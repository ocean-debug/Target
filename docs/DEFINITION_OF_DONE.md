# Definition of Done

## 每个工具模块

- [ ] 输入、输出符合 `schemas/` 中的版本化合同。
- [ ] 有真实实现，不只返回硬编码或LLM生成的示例。
- [ ] 有一个最小成功样例。
- [ ] 有一个失败、OOD或拒绝样例。
- [ ] 返回来源、版本、参数、warnings和limitations。
- [ ] 产生可查询的 `tool_run_id` 和 Trace。
- [ ] 被主 Agent 自动调用过。
- [ ] 至少由一名非作者成员复现。
- [ ] README说明用途、依赖、运行方法和科学边界。

## 每条科学结论

- [ ] 标记为 FACT / OBSERVED / PREDICTED / INFERRED。
- [ ] 能回链到EvidenceItem或ToolResult。
- [ ] 组织、细胞类型、疾病阶段和物种上下文明确。
- [ ] 方向、效应量、样本量或不确定性明确。
- [ ] 证据冲突和缺口未被隐藏。
- [ ] 因果措辞与证据设计匹配。

## 最终Demo

- [ ] 一个输入能够生成Plan并调用多个真实工具。
- [ ] 至少包含一个公开组学分析和一个扰动预测。
- [ ] 输出3～5张完整TargetCard。
- [ ] 关键结论可以回链。
- [ ] 有一个工具失败或上下文不匹配的展示。
- [ ] 非作者根据README完成复现。
- [ ] 五分钟演示连续成功三次。
