# Falsifiable Experiment Planning

## 适用
为优先级靶点设计体外、动物或临床前验证方案。

## 必含要素
1. 假设、模型体系、干预方向、阳性/阴性/非靶向对照。
2. 主要终点、次要终点、重复数与功效分析要求。
3. 预期阳性、阴性和矛盾结果分别对应什么结论。
4. 下一步最有信息价值的实验和停止条件。
5. 明确证据缺口与失败风险，不把实验方案写成确定性承诺。
